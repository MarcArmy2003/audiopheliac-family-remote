# The Audiopheliac Family Remote

## On this PC (Victus, Precision, any Windows box)
1. Install Node.js LTS if you do not have it: https://nodejs.org
2. Unzip this folder anywhere. Suggested: `C:\Users\gillo\The-Audiopheliac\family-remote`
3. Double-click **CREATE-DESKTOP-ICON.cmd** for a branded desktop icon.
4. Double-click **The Audiopheliac** (or **GO.cmd**). Allow the firewall. Leave the black window open.
5. The window prints the phone address, like `http://192.168.1.XXX:8099`

## iPhone
1. Same Wi-Fi as this PC. Not a guest network.
2. Open **Safari** (not Chrome, not Grok).
3. Go to the address from the black window.
4. Share → **Add to Home Screen** → Add.
5. Open the Audiopheliac icon.

## First live test
Gear → Find my devices. Hue: press the bridge button, then Link. Audio tab: Yamaha power and volume.
